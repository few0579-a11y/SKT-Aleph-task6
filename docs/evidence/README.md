# 증거 화면

배포본(https://skt-aleph-task6.vercel.app)에서 찍은 화면입니다.

2026-11-13에 화면 디자인을 바꾸고(계획 탭, 타임테이블, 캘린더 추가) **조회 화면은 새 디자인으로 다시 찍었습니다.**
시연용 할 일을 만들어 생성·수정·완료·삭제·더블클릭을 보여 준 **동작 화면**(표에 *이전 디자인* 표시)은 데이터를 더 늘리지 않으려고 이전 디자인에서 찍은 그대로 두었습니다. 기능과 서버 동작은 같습니다.

### 비밀값·XSS 점검 결과 (C57, C58)
`BASE_URL=https://skt-aleph-task6.vercel.app node scripts/check-security.mjs` → **6/6 PASS**

- CSP 헤더: `script-src 'self'`(외부·인라인 스크립트 차단)
- 배포 파일(`/`, `/app.js`, `/style.css`)·API 응답·오류 응답 13곳에 비밀값 없음
- 화면 코드에 `innerHTML`·`insertAdjacentHTML`·`document.write`·`eval` 없음(사용자 입력은 `textContent`로만 그림, 계산한 색·위치는 `el.style`로만 넣음)
- 저장소 파일과 Git 이력 전체(모든 커밋의 변경 내용)에 DB 연결 문자열·Supabase 키·JWT 없음, `.env` 파일 없음
- 브라우저 콘솔: 오류·로그 없음
- DB 연결 문자열은 Vercel 환경변수(Sensitive)에만 있고, 브라우저는 `/api/*`만 호출
