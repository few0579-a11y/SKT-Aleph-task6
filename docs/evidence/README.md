## 카드 2. 할 일 CRUD와 검색·필터링·정렬 (2026-11-12)

수정·완료·완료 취소·삭제는 실제 할 일(#1~#8)을 건드리지 않도록 **시연용 할 일 #9 "[시연] 삭제될 할 일"** 하나로 진행했습니다.
#9는 마지막에 삭제(소프트 삭제)되어 목록과 집계에서 빠졌습니다.

| 파일 | 기준 | 보이는 것 |
|---|---|---|
| `c2-1-create.jpg` | C09 생성, C14~C17 | #9가 마감일 2026-11-12, 우선순위 낮음, 태그 `시연`, 예상 10분으로 추가됨(9건) |
| `c2-2-edit.jpg` | C10 수정 | #9의 예상 시간 10분 → 20분, 태그 `수정됨` 추가 |
| `c2-3-complete.jpg` | C11 완료 | #9 상태 "완료", 취소선, 버튼이 "완료 취소"로 바뀜 |
| `c2-4-reopen.jpg` | C12 완료 취소 | #9 상태가 다시 "진행 중" |
| `c2-5-delete.jpg` | C13 삭제 | #9가 목록에서 사라지고 8건 |
| `c2-6-sort-due-asc.jpg` | C20 정렬 | "마감일 오름차순 → 같으면 ID 오름차순": 1, 2, **5, 7**(11/18), 3, **4, 6, 8**(11/25) |
| `c2-7-sort-estimate-desc.jpg` | C20 정렬 | "예상 시간 내림차순 → 같으면 ID 오름차순": 4(720), **7, 8**(630), **2, 3**(360), 1(240), **5, 6**(150) |
| `c2-8-search-filter.jpg` | C18 검색, C19 필터 | 검색 `5` + 우선순위 보통 → #5, #6 (검색만 하면 #2, #4, #5, #6) |

굵게 표시한 번호는 정렬 값이 같아 보조 정렬(ID 오름차순)로 순서가 정해진 할 일입니다.
